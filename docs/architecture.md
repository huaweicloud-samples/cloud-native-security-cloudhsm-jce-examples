# 架构说明

`cloud-native-security-cloudhsm-jce-examples` 提供 **云加密机（HSM）JCE 示例集**：用 Java JCE 标准接口对接硬件加密机，覆盖对称/非对称/签名/密钥管理等 26 个示例。华为云对应 DEW 云加密机（CloudHSM）。

## 使用形态

```
┌────────────────────────────────────────────────────────────────────┐
│                     Java 应用（JCE 标准接口）                      │
│                  Cipher / KeyStore / KeyGenerator                  │
└──────────────────────────────────┬─────────────────────────────────┘
                                   │ 标准 JCE 调用
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│              HsmProvider（DEW 云加密机 JCE Provider）              │
└──────────────────────────────────┬─────────────────────────────────┘
                                   ▼
┌────────────────────────────────────────────────────────────────────┐
│                      DEW 云加密机（HSM）实例                       │
│                          密钥不出硬件边界                          │
└────────────────────────────────────────────────────────────────────┘
```

## 核心组件

| 目录 | 说明 |
|---|---|
| `src/main/java/.../examples/` | 26 个示例类（AES/RSA/EC/HMAC/EdDSA/ML-DSA/密钥管理） |
| `pom.xml` | Maven 构建（依赖 DEW HSM JCE SDK，路径占位） |
| `docs/` | 架构 + 使用指导 |

## 设计说明

- JCE 为 Java 标准接口，算法流程零改动；仅 provider 初始化与登录适配 DEW
- 26 个示例按功能分组：对称加密 / 非对称 / 数字签名 / 密钥管理与登录
- 代码中 `HsmProvider.PROVIDER_NAME` 为平台 provider 占位，按所选 DEW HSM JCE SDK 校准
